# คู่มือตั้งมือถือดักจับเงินเข้า (MacroDroid) สำหรับ POS Hero

คู่มือนี้ตั้งให้มือถือ 1 เครื่อง (เครื่องที่มีแอปธนาคาร/ถุงเงิน/เป๋าตัง/แม่มณี) ส่งแจ้งเตือนเงินเข้ามาที่ POS Hero **2 ทางพร้อมกัน**

| ทาง | ต้องมีเน็ต | ต้องอยู่วงเน็ตเดียวกับคอม | กู้รายการที่หลุดได้ |
|---|---|---|---|
| ☁️ Firebase (หลัก) | ✅ (เน็ตใครก็ได้ ฮอตสปอตก็ได้) | ❌ | ✅ |
| 📶 วงเน็ตร้าน UDP (สำรอง) | ❌ | ✅ | ❌ |

เน็ตร้านดับแล้วคอมย้ายไปต่อฮอตสปอต Firebase ก็ยังรับได้ ถ้าไม่มีอินเทอร์เน็ตเลยแต่คอมกับมือถืออยู่วงเดียวกัน วงเน็ตร้านก็ยังรับได้

---

## ขั้นที่ 0 — เตรียมฝั่งคอม (ทำครั้งเดียว)

1. เปิด POS Hero → กดปุ่ม **⚙️ ตั้งค่า** ที่แผงปุ่มด้านล่าง → กล่อง **📥 ช่องทางรับเงินเข้า**
2. **Firebase**
   - ใส่ `Database URL` ของโปรเจกต์ Firebase (หน้า Realtime Database มุมบน เช่น `https://xxxx-default-rtdb.asia-southeast1.firebasedatabase.app`)
   - กด 🎲 เพื่อสุ่ม `Inbox Key` แล้วติ๊ก **เปิดใช้**
   - **กฎความปลอดภัย:** เอาเนื้อหาใน [`firebase-rules.json`](firebase-rules.json) ไป **รวม** กับกฎเดิมของ STOCK MASTER ในหน้า Rules
     ใส่เฉพาะก้อน `"pos_hero_inbox": {...}` เข้าไปข้างใน `"rules"` เดิม **อย่าวางทับทั้งหน้า** ไม่อย่างนั้นกฎเดิมจะหายหมด
     ให้ Boss ตรวจก่อนกด **Publish**
3. **วงเน็ตร้าน** — ติ๊ก **เปิดใช้** (พอร์ตค่าเริ่มต้น 47800) แล้วกด **🛡️ อนุญาตไฟร์วอลล์** → กด Yes ที่หน้าต่างขอสิทธิ์ admin
   บรรทัด "ไฟร์วอลล์" ต้องขึ้น ✅ (Windows มักจัดฮอตสปอตใหม่เป็นเครือข่าย Public ถ้าไม่มีกฎนี้ UDP จะถูกบล็อกเงียบๆ)
4. กด **📱 ข้อมูลสำหรับตั้ง MacroDroid** จะเห็น URL, key, พอร์ต และ JSON ที่ต้องใช้ พร้อมปุ่ม 📋 คัดลอกทีละช่อง
   (ส่งเข้า LINE ตัวเองแล้วเปิดบนมือถือจะสะดวกที่สุด)

---

## ขั้นที่ 1 — ติดตั้ง MacroDroid

1. ติดตั้ง **MacroDroid** จาก Play Store
2. ให้สิทธิ์ **Notification Access** (การเข้าถึงการแจ้งเตือน) ตอนแอปถามครั้งแรก
   ถ้าเผลอกดข้าม: ตั้งค่า → การแจ้งเตือน → การเข้าถึงการแจ้งเตือน → เปิด MacroDroid
3. **แบตเตอรี่ → ไม่จำกัด (Unrestricted)**: ตั้งค่า → แอป → MacroDroid → แบตเตอรี่ → ไม่จำกัด
   ถ้าไม่ตั้ง Android จะฆ่าแอปทิ้งเงียบๆ ตอนจอดับนาน แล้วแจ้งเตือนจะไม่ถูกส่งมาเลย
4. มือถือยี่ห้อ Xiaomi/Oppo/Vivo/Samsung มีเมนู "เริ่มอัตโนมัติ (Autostart)" หรือ "แอปที่ไม่ต้องพัก" เพิ่มอีกชั้น ให้เปิดให้ MacroDroid ด้วย

## ขั้นที่ 2 — Macro "ส่งเงินเข้า POS"

สร้าง Macro ใหม่ ตั้งชื่อ `ส่งเงินเข้า POS`

### Trigger (ตัวกระตุ้น)
**Notification Received (ได้รับการแจ้งเตือน)** → เลือกเฉพาะแอปที่ร้านใช้รับเงินจริง เช่น K PLUS, SCB EASY, ถุงเงิน, เป๋าตัง, แม่มณี
(ไม่ต้องกรองข้อความ POS Hero จะกรองคำว่า "เงินเข้า / รับโอน" และอ่านยอดเอง)

### Action 1 — สร้าง eventId
**Set Variable (ตั้งค่าตัวแปร)** → ตัวแปรภายใน (Local) ชนิด String ชื่อ `eventId`
ค่า = `[system_time]-[random_number]` (เวลาระบบ + เลขสุ่ม)
eventId นี้ใช้ครั้งเดียวต่อ 1 แจ้งเตือน และส่งไปทั้ง 2 ทาง POS Hero ใช้มันกันบันทึกซ้ำ

### Action 2 — ส่งขึ้น Firebase
**HTTP Request**
- Method: **POST**
- URL: ช่อง ① จากหน้าต่าง "ข้อมูลสำหรับตั้ง MacroDroid"
  (`<Database URL>/pos_hero_inbox/<Inbox Key>/events.json`)
- Content type: `application/json`
- Body: ช่อง ① Body

```json
{"eventId":"[lv=eventId]","title":"[not_title]","text":"[notification]","app":"[not_app_name]","pkg":"[not_app_package]","ts":{".sv":"timestamp"},"via":"fb"}
```

`{".sv":"timestamp"}` ต้องพิมพ์ตามนี้เป๊ะ Firebase จะแทนเป็นเวลาของเซิร์ฟเวอร์ให้เอง

### Action 3 — ส่งเข้าวงเน็ตร้าน (UDP)
**UDP Command**
- Destination: `255.255.255.255`  Port: `47800` (หรือพอร์ตที่ตั้งไว้)
- Message: ช่อง ② จากหน้าต่าง (มี `"k"` = 8 ตัวแรกของ Inbox Key อยู่แล้ว)

```json
{"k":"<8 ตัวแรกของ key>","eventId":"[lv=eventId]","title":"[not_title]","text":"[notification]","app":"[not_app_name]","ts":[system_time]}
```

### ⚠️ ข้อควรระวัง 1: Action 2 กับ 3 ต้องไม่รอกัน
ตอนไม่มีเน็ต HTTP ใน Action 2 จะล้ม **UDP ใน Action 3 ต้องยังถูกส่งอยู่**
- ถ้า HTTP Request มีตัวเลือก "ทำงานต่อแม้ล้มเหลว / Don't block" หรือ "Wait for result" ให้ตั้งไม่ให้รอผล
- วิธีที่ชัวร์กว่า: เรียง **UDP (Action 3) ไว้ก่อน HTTP (Action 2)** UDP ส่งเสร็จทันทีไม่มีวันค้าง

### Action 4 — ล้างแจ้งเตือนที่ส่งแล้ว (สำคัญ)
**Clear Notifications** (หมวด Notifications) → เลือกล้างเฉพาะแจ้งเตือนที่เป็นตัวกระตุ้น (triggering notification)

Android เก็บแจ้งเตือนค้างได้ประมาณ **50 รายการต่อแอป** ถ้าแจ้งเตือนของแอปธนาคารแอปเดียวค้างครบแล้ว
แจ้งเตือนเงินเข้าครั้งต่อไปจะถูกระบบทิ้งไปเฉยๆ MacroDroid มองไม่เห็นเลย ยอดนั้นจะหายแบบไม่มีสัญญาณเตือน
การล้างหลังส่งเสร็จจะกันไม่ให้แจ้งเตือนค้างจนเต็ม (ยอดยังอยู่ในตาราง POS และในแอปธนาคารครบ)
ถ้าอยากเห็นแจ้งเตือนค้างในมือถือไว้ ให้ทำ Macro แยกที่ล้างแจ้งเตือนธนาคารทุกคืนแทน

### ⚠️ ข้อควรระวัง 2: เครื่องหมายคำพูดและการขึ้นบรรทัดใหม่
ถ้าข้อความแจ้งเตือนมี `"` หรือขึ้นบรรทัดใหม่ JSON จะพัง แล้วรายการนั้นจะหาย
- ถ้า MacroDroid เวอร์ชันที่ใช้มีตัวเลือก **JSON encode / escape** ให้เปิด
- ถ้าไม่มี ให้เพิ่ม Action **Text Manipulation (แทนที่ข้อความ)** ก่อน Action 2/3: เก็บ `[notification]` และ `[not_title]` ลงตัวแปร แทนที่ `"` ด้วย `'` และแทนที่ขึ้นบรรทัดใหม่ด้วยช่องว่าง แล้วใช้ตัวแปรนั้นใน body แทน
- **ต้องทดสอบกับแจ้งเตือนจริงของทุกธนาคารที่ใช้** (ดูขั้นที่ 4) ถ้า JSON พัง POS Hero จะเขียนใน log ว่า "packet ที่อ่านไม่ได้ (JSON พัง)"

> ชื่อ Magic Text ในวงเล็บ `[...]` อาจต่างกันเล็กน้อยตามเวอร์ชัน MacroDroid ให้กดปุ่ม "…" ในช่องข้อความแล้วเลือกจากรายการ
> อย่าพิมพ์เอง ที่ต้องมีคือ หัวข้อแจ้งเตือน, ข้อความแจ้งเตือน, ชื่อแอป, เวลาระบบ, แบตเตอรี่

## ขั้นที่ 3 — Macro "heartbeat" (บอกคอมว่ามือถือยังทำงาน)

สร้าง Macro ใหม่ชื่อ `POS heartbeat`
- **Trigger:** Regular Interval (ทุกช่วงเวลา) → ทุก **5 นาที**
- **Action A — UDP Command:** `255.255.255.255:47800` ข้อความ ③ Heartbeat — UDP
  ```json
  {"k":"<8 ตัวแรกของ key>","hb":1,"battery":[battery]}
  ```
- **Action B — HTTP Request:** Method **PUT** URL ③ (`.../heartbeat.json`) Body:
  ```json
  {"ts":{".sv":"timestamp"},"battery":[battery]}
  ```

ถ้า heartbeat หายไปเกิน 12 นาที ไฟใน POS Hero จะเปลี่ยนจากเขียว และ tooltip จะบอกว่า "มือถือดักจับเงียบ"

## ขั้นที่ 4 — ทดสอบ

1. ใน POS Hero กด **🧪 โหมดทดสอบ** แล้วโอนเงินเข้าจริง 1 บาท หรือรอแจ้งเตือนถัดไป
   log จะแสดงยอด แหล่งที่มา และชื่อที่อ่านได้ โดย **ไม่บันทึกลงตาราง**
2. หรือทดสอบโดยไม่ต้องโอน: ใน MacroDroid กดทดสอบ Action/Macro โดยให้ title ขึ้นต้นด้วย `TEST`
   แจ้งเตือนที่ title ขึ้นต้น `TEST` ถือเป็นการทดสอบเสมอ ทุกช่องทาง ไม่ถูกบันทึก
3. ดูบรรทัดสถานะในกล่อง 📥 (หน้า ⚙️ ตั้งค่า) และไฟใน 📡 สถานะรับเงินเข้า (หน้า 🔍 ตรวจเช็คเงินโอน):
   - ☁️ Firebase เขียว = ต่ออยู่และได้ heartbeat
   - 📶 วงเน็ต เขียว = ได้ยิน packet/heartbeat ภายใน 12 นาที
4. ทดสอบทีละทาง: ปิดเน็ตมือถือ (ให้เหลือแค่ UDP) แล้วส่ง TEST → log ต้องขึ้น 📶
   จากนั้นให้มือถือกับคอมอยู่คนละวง → log ต้องขึ้น ☁️

## ขั้นที่ 5 — ข้อแนะนำเรื่องฮอตสปอต

- ตั้งมือถือที่ปล่อยฮอตสปอต **ไม่ให้ตัดฮอตสปอตอัตโนมัติ** เมื่อไม่มีคนใช้ (ตั้งค่า → ฮอตสปอต → ปิดฮอตสปอตอัตโนมัติ → ไม่เลย)
- **เสียบชาร์จ** ทั้งมือถือดักจับและมือถือที่ปล่อยฮอตสปอต
- ถ้าคอมต่อฮอตสปอตของคนอื่น ให้ **มือถือดักจับต่อฮอตสปอตเดียวกันด้วย** วงเน็ตสำรอง (UDP) จะยังใช้ได้ถ้าเน็ตฮอตสปอตหมด
- สลับ Wi-Fi ร้าน ↔ ฮอตสปอต ขณะที่ POS Hero เปิดอยู่ได้เลย แอปจะรู้ภายในประมาณ 4 วินาทีแล้วต่อทุกช่องทางใหม่เอง
- ถ้ามีแถบแดง **"⚠️ 12:03–12:05 ขาดการเชื่อมต่อ ตรวจยอดในแอปธนาคารช่วงนี้"** แปลว่าช่วงนั้นไม่มีช่องทางไหนกู้รายการได้
  ให้เปิดแอปธนาคารดูยอดช่วงเวลานั้น แล้วใส่เพิ่มเองถ้าตกหล่น ตรวจแล้วกด ✓ เพื่อปิดแถบ

## ปัญหาที่พบบ่อย

| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| ☁️ แดง log ว่า "http 401" หรือ "ไม่มีสิทธิ์อ่าน" | ยังไม่ได้ใส่กฎใน Firebase หรือ Inbox Key สั้นกว่า 32 ตัว |
| ☁️ ล้างข้อมูลเก่าไม่สำเร็จ "http 400" | กฎยังไม่มี `".indexOn": ["ts"]` ใต้ `events` |
| 📶 ไม่เคยได้ยินเลย | ยังไม่กด 🛡️ ไฟร์วอลล์ / มือถือกับคอมคนละวง / พอร์ตไม่ตรง / 8 ตัวแรกของ key ใน `"k"` ไม่ตรง |
| log "JSON พัง" | ข้อความมี `"` หรือขึ้นบรรทัดใหม่ ดูข้อควรระวัง 2 |
| ไฟเขียวแต่ไม่มีรายการเข้า | Trigger ไม่ได้เลือกแอปธนาคารนั้น / MacroDroid ถูกปิดสิทธิ์ Notification Access |
| รายการเดียวขึ้น ✓✓ | ปกติ แปลว่ารับได้จากหลายช่องทาง และบันทึกไว้แค่ 1 รายการ |
