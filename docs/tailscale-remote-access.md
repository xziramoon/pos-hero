# ใช้มือถือกับ POS Hero จากนอกร้าน (คนละวง LAN) ผ่าน Tailscale

ปกติแอป "POS Relay" บนมือถือกับ POS Hero บน PC ต้องอยู่ WiFi/LAN วงเดียวกันในร้าน
ถึงจะส่งแจ้งเตือนธนาคารข้ามเครื่องกันได้ (ดูกล่อง "📱 มือถือดักแจ้งเตือน (LAN Relay)"
ในหน้าโปรแกรม) เอกสารนี้อธิบายวิธีทำให้ใช้งานได้แม้มือถือไม่ได้ต่อ WiFi ร้าน (เช่น
ใช้เน็ตมือถือ/4G-5G อยู่นอกร้าน) โดยไม่ต้องเช่า VPS, ซื้อโดเมน หรือทำ TLS เอง —
ใช้ [Tailscale](https://tailscale.com) (ฟรีสำหรับใช้ส่วนตัว/ร้านเล็กๆ) สร้างเครือข่ายส่วนตัว
เสมือนเชื่อม PC กับมือถือเข้าด้วยกันแทน

ทั้งหมดนี้**ไม่ต้องแก้โค้ดฝั่งแอปเลยแม้แต่บรรทัดเดียว** — ช่อง "ที่อยู่ Relay Server"
ในแอปมือถือรับ IP อะไรก็ได้ที่ไปถึง PC ได้จริง (ไม่ได้ผูกไว้กับวง 192.168.x.x/10.x.x.x
เท่านั้น) แค่เปลี่ยนจาก IP วง LAN เดิม ไปเป็น IP ของ Tailscale แทน

## หลักการคร่าวๆ

- Tailscale จะติดตั้ง "การ์ดเครือข่ายเสมือน" บนทั้ง PC และมือถือ แล้วให้ IP วงพิเศษ
  (ขึ้นต้นด้วย `100.x.x.x`) กับแต่ละเครื่องที่ล็อกอินบัญชี Tailscale เดียวกัน (เรียกว่า
  tailnet เดียวกัน)
- IP วง `100.x.x.x` นี้ใช้งานได้เหมือน IP วง LAN ทุกประการ — PC ยังคงเป็นฝั่ง "server"
  เหมือนเดิม (มือถือเป็น server เองไม่ได้ เพราะเน็ตมือถือส่วนใหญ่อยู่หลัง Carrier-grade
  NAT ที่ device ภายนอกยิงเข้าหาตรงๆ ไม่ได้)
- ข้อมูลที่วิ่งผ่าน Tailscale ถูกเข้ารหัสด้วย WireGuard อยู่แล้วในชั้น tunnel เอง
  ต่อให้ตัวแอปคุยกันด้วย `http://` (ไม่ใช่ `https://`) ข้อมูลจริงที่วิ่งบนอินเทอร์เน็ตก็ยัง
  ถูกเข้ารหัสอยู่ดี

## ขั้นตอนติดตั้ง

### 1) ติดตั้ง Tailscale บน PC (เครื่องที่รัน POS Hero)

1. ไปที่ https://tailscale.com/download แล้วดาวน์โหลดตัวติดตั้งสำหรับ Windows
2. ติดตั้งตามปกติ แล้วล็อกอิน (สร้างบัญชีใหม่ได้ฟรี เช่นด้วย Google/Microsoft account)
3. เปิด PowerShell หรือ Command Prompt แล้วรัน `tailscale ip -4` เพื่อดู IP ของเครื่องนี้
   (รูปแบบ `100.x.x.x`) — จดไว้ หรือจะเปิดดูทีหลังจาก
   https://login.tailscale.com/admin/machines ก็ได้ (คลิกเข้าไปที่ชื่อเครื่อง PC จะเห็น IP)

### 2) ติดตั้ง Tailscale บนมือถือ

1. โหลดแอป "Tailscale" จาก Play Store (หรือถ้าโหลดจาก Play Store ไม่ได้ ใช้ APK จาก
   หน้าดาวน์โหลดของ Tailscale โดยตรง)
2. เปิดแอป แล้วล็อกอิน**ด้วยบัญชีเดียวกันกับที่ใช้ล็อกอินบน PC** (ข้อนี้สำคัญที่สุด —
   ต้องอยู่ tailnet เดียวกัน ไม่งั้นมองไม่เห็นกัน)
3. กด "Connect"/เปิดสวิตช์ให้ Tailscale ทำงานอยู่ (ไอคอนจะขึ้นในแถบสถานะเหมือน VPN ทั่วไป)

### 3) หา Tailscale IP ของ PC

ทำได้หลายทาง เลือกทางใดทางหนึ่ง:

- รันคำสั่ง `tailscale ip -4` บน PC (เร็วที่สุด)
- เข้า https://login.tailscale.com/admin/machines แล้วดูคอลัมน์ IP ของเครื่อง PC
- เปิด POS Hero แล้วกดปุ่ม **"📶 ดูข้อมูลเชื่อมต่อ (IP/Token)"** ในกล่อง Relay — ถ้า
  Tailscale เปิดอยู่ตอนนั้น อาจเห็น IP มากกว่าหนึ่งอัน (ทั้ง IP วง LAN เดิม และ IP วง
  `100.x.x.x` ของ Tailscale) เพราะปุ่มนี้ดึงทุก IP ที่เครื่องมีอยู่ในตอนนั้นมาแสดงพร้อมกัน
  — ให้เลือกใช้ตัวที่ขึ้นต้นด้วย `100.` ตอนตั้งค่าจากนอกร้าน

### 4) ตั้งค่าในแอปมือถือ

1. เปิดแอป "POS Relay" บนมือถือ
2. ในช่อง **"ที่อยู่ Relay Server (ip:port)"** ลบ IP วง LAN เดิมออก แล้วใส่
   `<Tailscale IP ของ PC>:<port>` แทน เช่น `100.101.102.103:8788`
   (พอร์ตยังเป็นพอร์ตเดิมที่ POS Hero ใช้อยู่ — ค่าเริ่มต้นคือ `8788` ดูพอร์ตจริงได้จาก
   ปุ่ม "ดูข้อมูลเชื่อมต่อ" ในขั้นตอนที่ 3)
3. ช่อง **"Relay Token"** ใส่ค่าเดิมที่เคยใช้ตอนอยู่ในร้าน (token ไม่เปลี่ยนตาม
   เครือข่าย — เอาค่าเดิมมาใช้ต่อได้เลย ไม่ต้องคัดลอกใหม่ถ้าเคยตั้งไว้แล้ว)
4. กด **"ทดสอบเชื่อมต่อ"** เพื่อเช็คว่าเข้าถึง PC ได้จริง ถ้าขึ้น "เชื่อมต่อ server สำเร็จ"
   ก็กด **"บันทึก"** ได้เลย
5. ทดสอบเพิ่มเติมด้วยปุ่ม **"ทดสอบส่งรายการโอนจำลอง"** เพื่อให้แน่ใจว่ารายการทดสอบ
   ขึ้นในหน้า POS Hero จริง

จากนี้มือถือจะยิง heartbeat/แจ้งเตือนไปหา PC ผ่าน Tailscale ได้ตลอด ไม่ว่าจะอยู่ WiFi
ร้าน หรือใช้เน็ตมือถืออยู่ที่ไหนก็ตาม ไม่ต้องสลับ IP ไปมาระหว่างอยู่ร้าน/นอกร้านด้วย
(ถ้าอยากได้ IP ที่ใช้ได้ทั้งสองที่ในช่องเดียว ให้ใส่ Tailscale IP ไว้เลยแม้ตอนอยู่ในร้าน
ก็ยังใช้ได้ปกติ เพราะ Tailscale ไม่ได้ตัดการเชื่อมต่อ LAN เดิมออก)

## ⚠️ จุดที่ต้องเช็คเอง: Windows Firewall (ห้ามข้าม)

ตัว POS Hero **ไม่ได้ตั้งค่า Windows Firewall ให้อัตโนมัติ** (ไม่มีสคริปต์ `netsh` หรือ
ตัวติดตั้งที่เปิดพอร์ตให้เองอยู่ในโค้ด) เวลาที่ Windows เจอโปรแกรมเปิดพอร์ตรับ connection
ครั้งแรก มันจะเด้งกล่อง "Windows Defender Firewall has blocked some features of this app"
ให้เลือกว่าจะอนุญาตบนเครือข่ายประเภทไหน (Private / Public)

**นี่คือจุดที่ Tailscale มักมีปัญหา:** การ์ดเครือข่ายเสมือนของ Tailscale (Tailscale
Tunnel adapter) บน Windows บางเครื่องจะถูกจัดเป็นประเภท **Public** หรือ **Unidentified
network** แทนที่จะเป็น Private ถ้าตอนเด้งกล่องแรกผู้ใช้เลือกอนุญาตเฉพาะ "Private
networks" (ซึ่งเป็นตัวเลือกที่คนส่วนใหญ่เลือกเพราะดูปลอดภัยกว่า) การเชื่อมต่อจากมือถือ
ผ่าน Tailscale จะ**ถูกไฟร์วอลล์บล็อกเงียบๆ** ทั้งที่ตั้งค่า IP/token ถูกต้องทุกอย่างแล้ว
(อาการที่เห็น: "ทดสอบเชื่อมต่อ" บนมือถือ timeout/เชื่อมต่อไม่ได้ ทั้งที่ IP ถูก)

**เอกสารนี้ตั้งใจไม่แก้ไฟร์วอลล์ให้อัตโนมัติ** (เป็นการเปลี่ยนสิ่งที่ทราฟฟิกอะไรผ่านเข้าเครื่องได้บ้าง
ควรให้เจ้าของเครื่องเป็นคนตัดสินใจเอง) ให้ผู้ดูแลเครื่อง PC เลือกทำเองวิธีใดวิธีหนึ่งต่อไปนี้:

**ทางเลือกที่ 1 (แนะนำ — เจาะจงกว่า ปลอดภัยกว่า): ตั้งให้ Windows มองเครือข่าย Tailscale เป็น Private**

- เปิด **Settings → Network & Internet → Ethernet** (หรือ **Wi-Fi**, Tailscale adapter
  มักโผล่มาเป็นการ์ดแยกในหน้านี้ ชื่อประมาณ "Tailscale Tunnel" หรือ "Unidentified network")
- คลิกเข้าไปที่การ์ดนั้น แล้วเปลี่ยน **Network profile type** จาก Public เป็น **Private**
- วิธีนี้ Tailscale เองก็แนะนำไว้ในเอกสารทางการเช่นกัน เพราะทำให้กฎ Firewall เดิมที่
  อนุญาตเฉพาะ Private ครอบคลุมทราฟฟิกจาก Tailscale ไปด้วยโดยไม่ต้องเปิดพอร์ตให้ Public
  ทั้งวง (ปลอดภัยกว่าทางเลือกที่ 2)

**ทางเลือกที่ 2 (ถ้าทางเลือกที่ 1 ทำไม่ได้/ไม่ขึ้นให้เลือก): เพิ่มกฎไฟร์วอลล์เจาะจงพอร์ต POS Hero ให้ครอบคลุม Public/Private ทุกโปรไฟล์**

เปิด PowerShell **แบบ Run as Administrator** แล้วรัน (ปรับเลขพอร์ตให้ตรงกับพอร์ตจริงที่
เห็นในปุ่ม "ดูข้อมูลเชื่อมต่อ" ของ POS Hero — ค่าเริ่มต้นคือ `8788`):

```powershell
netsh advfirewall firewall add rule name="POS Hero Relay (Tailscale)" dir=in action=allow protocol=TCP localport=8788 profile=any
```

คำสั่งนี้เปิดเฉพาะพอร์ต TCP ของ POS Hero เท่านั้น (ไม่ได้เปิดทั้งเครื่องหรือทั้งโปรแกรม)
ให้รับ connection จากทุกโปรไฟล์เครือข่าย (Private/Public/Domain) — แคบกว่าและปลอดภัยกว่า
การกดอนุญาตทั้งโปรแกรมแบบ "Public networks" ในกล่อง popup ของ Windows

> ทั้งสองทางเลือกด้านบนต้องทำเองบนเครื่อง PC โดยผู้ดูแลระบบ/เจ้าของร้าน — เอกสารนี้ไม่ได้
> รันคำสั่งเหล่านี้ให้ และไม่แนะนำให้เปิดพอร์ตกว้างกว่าที่จำเป็น

## หมายเหตุความปลอดภัย

- Token ของ Relay ทำหน้าที่เหมือนรหัสผ่าน — ต่อให้ใช้ Tailscale (ซึ่งเข้ารหัสทราฟฟิกอยู่แล้ว)
  ก็อย่าแชร์ token ให้คนนอกร้าน เพราะใครก็ตามที่มีทั้ง IP และ token จะยิงรายการปลอมเข้า
  POS Hero ได้
- ถ้าไม่ได้ใช้งานนอกร้านแล้ว ปิด Tailscale บนมือถือ/PC ได้ตามปกติ ไม่กระทบการใช้งานในวง
  LAN เดิม (แอปยังใช้ IP วง LAN เดิมได้ควบคู่กันอยู่)
